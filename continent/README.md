# 大陸：舊王國的傳說

從封建版六角世界（feudal 分支的 `src/sim.js`）分出來的獨立副本。開局只有統一大陸的金冠王國，少年王與九位傳奇各持一把傳奇武器（大賢者持「星杖」）。亞瑟王式的崩解一定會發生，細節交給模擬；之後再跑 380 多年，看傳奇的家族與武器長出什麼故事。蠻族先用盜匪幫派代替。

- `node continent/run.mjs 大陸-6`：一個種子的完整傳說（興亡、結局、每把武器的流轉、四百年後的列國、家族恩怨）
- `node continent/summary.mjs 8`：8 個種子的彙整

## 注定的崩解（第 14～20 年之間觸發）
1. 大賢者在古林中失蹤，「星杖」被封；海歌騎士為愛而死；白騎士出發尋找聖物（若醜聞先爆發就留下來）
2. 王甥揭發王后與王之劍的私情 → 劫法場、誤殺岑翎 → 王之劍帶王后出奔、據城自立，好感夠的傳奇跟他走
3. 兩三年後：岑烈與王之劍決鬥；王甥趁王出征在首都篡位
4. 隔年最終決戰：王與王甥同歸於盡（王有一成五機會多撐一兩年）；忠臣把「誓約」拋回水中
5. 王身後無嗣，握有封地的傳奇各自據地自立；王之劍六成機率出家

劇情進行中，關鍵人物不會戰死或老死，關鍵首都不會被攻破。

## 加上的系統
- **傳奇武器**：主將戰力 +0.1～0.2（星杖 +0.4）。戰死時四成五被敵將奪走、三成遺落戰場、其餘由家人帶回；國破時歸征服者；國君會把寶庫裡的武器賜給沒有武器的將領；遺落的每年 2.5% 機率被附近的國家或盜匪尋回（水中 0.15%、古林 0.3%）
- **國君與家族**：每國有國君；死後八成五由子嗣繼位，否則「身後無嗣」引發爭位、改由別家入主
- **好感與家族恩怨**：傳奇之間有好感；家族之間的恩怨會提高兩國的緊張（每年衰減 0.4%）
- **盜匪代替蠻族**：幫派上限 7、出現機率提高；握有傳奇武器的山寨聲勢大振

## 第二輪：崩解多種走法與流轉的世界

- **崩解多種走法**：揭發者（王甥／家宰／侍女）、王后被燒死或被劫走、劫法場時是否誤殺；王甥可能在舊都或自己封地起兵、找盜匪當盟友；甘蘭之戰王之劍可能趕到、王可能多活幾年、王甥可能逃走；王死後由凱、貝德維爾或高文其中一人擲劍。
- **站隊**：傳奇依對王與對王之劍的好感決定（基準 35%），沒有封地的傳奇可以隻身投奔。實際上第 17 年左右還活著且留在王身邊的傳奇只剩 2–3 位，所以站隊人數通常是 0–1。
- **世仇**：殺親之仇 −0.5 起跳；|好感|>1 時每年只衰減 0.07%，大仇能延續幾百年。同一家族統治的國家不互打。
- **武器轉手**：聯姻嫁妝（每位國君只結一次親，同兩家 40 年內不重複）、被盜、殺人奪寶、饑荒典當、賜給不忠的封臣、戰場俘虜（12%）。
- **有名者流轉**：英雄會投奔他國、落草為寇；俘虜可以被贖回、投降或被處決。
- **好感網**：每位英雄對其他英雄都有好感，家族之間另有好感；國君絕嗣時，姻親家族有一半機率入主。

## 第三輪：把經濟層接上傳說層

- **商路熱度**：每支商隊把貨值記在沿路每一格與每一段路上，每年衰減 7%（大約記得十幾年）。快照裡帶 `edges`（最熱的 160 段路）。
- **名聲**：英雄打贏一場得 0.25 分，再依戰場附近的商路熱度最多加 1.75 分（`FAMEK`=1500）。累積到 6 分（`FAMET`），事蹟就「跟著商隊傳開」，英雄得到綽號、進入傳說。冷僻地方的勝仗傳不出去。
- **商人贖回武器**：方圓 7 格內最富裕的市集（人口、存貨、商路熱度）夠有錢（`RICH`=400），就會從盜匪手上買回傳奇武器，或向撿到古兵器的農夫收購，獻給所屬國家。
- **劫商隊起家**：商隊被劫時，附近的盜匪累積財貨（盜匪實力最多加 160，每年花掉 15%），第一次累積到 `BIGLOOT` 就「從此坐大」。附近沒有盜匪的話，劫匪可能就此拉起一支人馬。日後自立為王時，會記得當年劫了哪支商隊。
- **饑荒熱度**：市集缺糧（糧食比例低於 0.8）時，該格與鄰格累積熱度，每年衰減 3%。快照裡帶 `famine`。
- `run.mjs` 多了三段：商路上傳開的名字、靠劫商隊起家的盜匪、商人贖回的傳奇武器。
