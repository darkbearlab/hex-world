# 像素工作室

放在 Cloudflare 上的私人像素繪圖工作區：作品存在伺服器，任何裝置打開都接得上；離線也能畫，連線後自動同步。

- 網址：https://studio.darkbearlab.workers.dev
- 登入：GitHub repo 的 secret `STUDIO_KEY` 就是密語，沒設定時一律拒絕登入。登入狀態保留 30 天；同一 IP 15 分鐘內錯 8 次會被暫時擋下。
- 工具：鉛筆、橡皮擦、填色、滴管、移動畫面；筆刷 1–8；圖層（新增、複製、上下移、合併、刪除、隱藏、不透明度、改名）；復原／重做；PNG 匯出（可放大）。
- 輔助：鏡像編輯（左右／上下／四向，按 M 切換，鉛筆、橡皮擦、填色都會跟著鏡像）；等分參考線（2／3／4／8 等分或每 8／16 格）。兩者設定跟著作品存。
- 作業模式（上方選單；新作品也能先選）：
  - 自由：不限顏色。
  - GBA 16 色：顏色貼齊 GBA 的 15-bit（每色 32 階），色票就是這張 sprite 的索引色票，最多 15 色加透明；不能半透明。切換時舊圖會自動轉換，可用 ↶ 復原。
- 明暗筆刷（☀ L／☾ D）：加亮時偏暖、亮部稍降彩度；壓暗時偏冷、彩度稍升。一筆裡同一格只變一次。GBA 模式下新顏色會自動加進色票；色票滿了或按了「🔒 鎖定」就只在色票裡找最接近的上一階／下一階。
- 色數：上方「色數 n/15」超過會變紅；點開看每個顏色用了幾格，可以標出位置，或把某色全部換成目前顏色。
- 圖片轉像素：作品列表的「從圖片轉像素…」（做成新作品）或編輯器上方的「匯入圖片」（放成新圖層）。選圖、拖進來或貼上都可以。左邊原圖上的黃框是取樣框，拖曳移動、滾輪或雙指縮放；也能用方向鍵或按鈕一次移 1 個原圖像素，或直接輸入 X、Y 和「每格幾個原圖像素」。右邊即時預覽。取樣方式有主色／平均／中心點，可以減色（中位切割）、只用目前色票、把背景色變透明；GBA 作品會自動貼齊 15-bit。
- 快捷鍵：B 鉛筆、E 橡皮擦、G 填色、I 滴管、H 移動、按住 Alt 暫時滴管、空白鍵拖曳平移、滾輪縮放、[ ] 筆刷大小、# 格線、0 置中、Ctrl+Z / Ctrl+Shift+Z、Ctrl+S 立刻同步。手機：單指畫、雙指縮放平移。
- 存檔：每次改動先存在這台裝置（IndexedDB），約 1.5 秒後同步到伺服器（Durable Object 的 SQLite）。
- 版本：伺服器每隔至少 2 分鐘記一個歷史版本，每件作品保留 50 個，可在「版本」裡還原。
- 衝突：兩台裝置同時改同一件作品時不會互相蓋掉，後到的那邊另存成「（衝突副本）」。
- 刪除：先進垃圾桶，可救回；在垃圾桶裡才能永久刪除。「匯出全部備份」下載一份 JSON。

本機測試：在 `studio/.dev.vars` 寫 `STUDIO_KEY=隨便`，然後 `npx wrangler dev --config studio/wrangler.toml`。
