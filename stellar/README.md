# 已知世界（Stellar Notes）劇本測試

把《Stellar Notes》的世界筆記（The Known World、引導的年代）當成開局條件，從「兩百年前、帝國還握有北方」開始推演 200 年，檢查模擬會不會自己走到筆記描寫的「現在」。

這是從 `src/sim.js`（feudal 分支）分出來的獨立副本，改動不會影響原本的六角世界。

| 檔案 | 內容 |
| --- | --- |
| `sim.js` | 劇本版模擬核心：固定地圖、13 個開局勢力與特性、銀兩與過路費、傭兵團、移民、選帝侯選舉、聯姻、獸人、北境自由民、林中軍閥、氣候變冷 |
| `lore.js` | 設定對照：把筆記對「現在」的 16 條描述寫成判定 |
| `lorecheck.mjs` | `node stellar/lorecheck.mjs 12`：跑 12 個種子，統計每條成立幾次（加 `DETAIL=1` 看細節） |
| `template.html`、`build.mjs` | `node stellar/build.mjs` 產生 `dist/stellar-lab.html` 實驗室頁面 |

## 為了貼合設定而加的規則

- 選帝侯之間打仗只割地、不臣屬（帝國的「憲法」）
- 精靈與北境自由民不主動開戰；精靈只住森林、使節會降低各國緊張
- 林中軍閥：不築城、森林防禦加成、平時越界劫掠、當封臣時忠誠反覆、丟了據點會退進森林再捲土重來
- 獸人：從北邊不斷南下，北方有強敵時推舉共主，外敵退去就分裂
- 前八十年北方逐漸變冷
- 獸人只有在北方有強敵（人類握有 25 格以上）時才結盟，外敵退去或共主一死就分裂
- 雅蘭追爾的招募掮客到鄰近外國找人當兵（「這裡不行了，不如一起去雅蘭追爾吧」），一半成為外籍傭兵、一半落地生根
- 傭兵上限為本國徵召兵力的六成；國庫不必累積，賺來的錢多半花在傭兵上
- 列羅多斯老兵優勢消退時，選帝侯會議上會被別人揶揄

## 蛇紋者劇本

實驗室推演完 200 年後按「🐍 降下蛇紋之夜」，或用 `node stellar/serpentcheck.mjs 6 40`（6 個種子、蛇紋之夜後再跑 40 年）。

- 那一夜，離開過精靈森林的人身上的蛇紋變成力量：開局約 8 名，之後每年可能再出現；跟精靈往來越多的國家（格林瓦德最多）越容易出現
- 一人抵萬軍：蛇紋者上陣時，直接替所屬的一方加上 250～600 的戰力（相當於一個中型國家的全部兵力）
- 蛇紋者打過的地方人口銳減、森林可能燒成焦土；他們很少戰死，但每年有 3% 會被蛇紋反噬
- 握有蛇紋者的國家有一半機率轉為主戰：侵略性提高、四處樹敵；鄰國也會因為害怕而敵視它
- 有錢的國家會出價挖角忠誠低的蛇紋者（銀兩付給原主）
- 主戰的國家會南下攻打精靈森林，說要找出蛇紋的源頭；精靈王都陷落，女王伊爾瓦納就殞命，世界失去指引（遠路運輸損耗變大、各國人心浮動、精靈不再調停）

## 滅世大火與引導的年代

實驗室按「🔥 滅世大火」，或 `node stellar/firecheck.mjs 6 30`（200 年 → 蛇紋之夜 → 30 年後大火 → 再跑 30 年）。

- 賽琳娜把軍隊與蛇紋者燒成灰燼：南方與舊帝國心臟損失四到六成人口，北方一成，列羅多斯幾乎無損
- 帝國心臟、雷頂峰、格林瓦德、精靈森林的掌權者必亡，其他南方王國與小國半數覆滅；每座市鎮變成一個莊園，名聲差的領主被推翻，領地化為無主之地
- 指引塔建在精靈女王的王座前；每年用「人口 × 死亡率 + 戰死」算出每天的靈魂數（1 單位人口約 600 人），對照一千的需求得出亮度；不夠亮時遠路難走、盜匪變多
- 艾琳卓希爾的新秩序：魁儡兵用石材與鐵打造，不吃糧也不看人口；周圍的莊園陸續效忠
- 列羅多斯置身事外，只有缺糧時才會南下；雅蘭追爾把翡翠海岸收為附庸，拿銀子資助還沒倒向新秩序的莊園；索辣拉爆發燈塔信仰與太陽信仰的衝突

## 判定的寬嚴

「凱基雅賣不進艾文鐸」與「列羅多斯兵最精」標為可接受的偏差（△）：前者一半世界成立就算數，後者消退了也能寫成「你們的人早就不會打仗了」。
