# 通關機器人（clear bot）

使用者要求（2026-09-30）：「我要持續試玩一陣子，你先看能不能改善機器人，但不要納入測試使用，純粹寫個通關機器人那樣，說不定將來除名幹員可以直接用類似邏輯。」

- 位置：`tools/clear-bot/`。這是開發工具，**不在 `npm test`、身分基準（`qa/enemy-data-identity.mjs`）或任何基準裡**，也不改 `src/` 與 `tools/balance.mjs`（測試與身分基準用的舊機器人照舊）。
- 只用玩家能做的公開呼叫：`game.action(type,arg)`、`game.target=id`、`game.choosePerk(id)`（`src/replay.js` 列出的四種操作；`recoverOperator` 只在無盡模式有用，撤離任務用不到）。從不直接改遊戲狀態。
- 決定論：不讀 `Math.random` 或時間；同一個種子每次玩出同一局（需要亂數時用 `util.mjs` 的 `seededRng(seed)`，目前的策略沒有用到）。
- 一局從新遊戲存檔的 `Game.restore` 開始，和操作紀錄一樣，所以加不加 `--log` 玩出來都相同。

## 1. 用法

**語言：預設英文**（使用者 2026-10-01：之後的影片先做英文版，機器人也用英文跑；中文、其他語言或不挑語言的回放，等要上 itch.io 以外的平台時再考慮）。`tools/clear-bot/lang-default.mjs` 在任何遊戲模組讀語言之前，把沒設定的 `ASH_LANGUAGE` 設成 `en`；要中文時明確給 `ASH_LANGUAGE=zh-TW`。英文的紀錄要在英文介面重播（瀏覽器的 `qa-ash-language` 設成 `en`），Node 裡用 `ASH_LANGUAGE=en`。第一、二輪留下的回放是中文錄的。

```bash
node tools/clear-bot/run.mjs                       # 8 職業 × 3 派系（忠誠、叛軍、蟲族）× 8 種子，標準難度，撤離任務
node tools/clear-bot/run.mjs --classes soldier,recon --factions rebel --difficulty hard --seeds 20 --seed-from 101
node tools/clear-bot/run.mjs --log runs/clear-bot  # 每局另存操作紀錄（src/replay.js 格式），可在 ?test=1 的回放器播放
node tools/clear-bot/trace.mjs --class ninja --faction swarm --seed 2 --last 30 [--options] [--map]
node tools/clear-bot/compare.mjs before.json after.json   # 兩次 --json 結果逐種子配對比較
```

`run.mjs` 選項：`--classes a,b`、`--factions loyalist,rebel,swarm`、`--difficulty easy|standard|hard`、`--mission extraction`、`--seeds N`、`--seed-from K`、`--parallel P`（預設 CPU 數 −1，最多 12）、`--log 目錄`、`--no-compare`（不跑舊機器人）、`--max-actions N`（預設 8000）、`--balance-actions N`（舊機器人的上限，預設 4000）、`--json 檔`（全部結果）、`--map-known`（見第 3 節）。

每個職業 × 派系一列：勝場、平均到達樓層、回合（有贏的局取贏的局，否則全部）、擊殺、最低生命的平均、卡住（到上限還在玩）的局數、最常見的死因（`兵種@樓層`），以及同樣種子上 `tools/balance.mjs` 的 `play` 的勝場與平均樓層。最後印總計、死因、各樓層死亡數與暴露輪廓（第 6 節）。

`compare.mjs` 把兩次 `--json` 的結果照（職業、派系、難度、種子）配對，列出兩邊的勝場、平均樓層，以及「輸變贏」「贏變輸」的種子數；機器人是決定論的，同一個種子在沒改到的職業上結果完全相同，所以配對比兩個勝率少很多雜訊。

`trace.mjs` 從頭重玩一個種子，每個決定印一行（回合、樓層、位置、生命＋護甲板、動作、理由、目前的計畫、看得到的敵人、記得的敵人、預告格）；`--options` 另列戰鬥選項的分數，`--map` 畫周圍 15×15（`@` 自己、`e` 敵人、`!` 正在蓄力、`B` 頭目、`&` 友軍、`c` 平民、`x` 預告格、`#` 牆）。

## 2. 架構

三層，接縫都是一般物件，之後可以拿去驅動其他單位（第 5 節）。

| 檔案 | 做什麼 |
| --- | --- |
| `perception.mjs` | `buildView(game,memory,options)` 產生 `view`：只含這一方從畫面知道的東西 |
| `memory.mjs` | 機器人自己記的事：看過又消失的敵人（ghost）、放棄的目標、暫時不理的敵人 |
| `bot.mjs` | `ClearBot`：每一步 感知 → 決定 → 執行；非戰鬥時的撿拾、終端、探索、出口；升級選擇 |
| `combat.mjs` | 戰鬥選項與評分（同一個單位：生命點） |
| `stance.mjs` | 有承諾的多回合計畫：退到掩護、守住、撤到視線外、走到射擊位置 |
| `tactics.mjs` | 估算：某格會吃多少傷害、我方這一擊的命中與擊殺機率、敵人的價值、爆炸 |
| `loadout.mjs`、`arsenal.mjs` | 第二輪：武器的用途與整包對這一局敵人的覆蓋分數；撿、換、拆、終端改裝與買彈、平常拿哪把（第 3.6 節） |
| `nav.mjs` | 只在探索過的地圖上尋路；危險格與危險地形加成本 |
| `classes/*.mjs` | 八個職業的鉤子（第 4 節） |
| `play.mjs`、`run.mjs`、`trace.mjs`、`compare.mjs`、`measure.mjs` | 一局、命令列、逐步追蹤、兩次結果的配對比較、暴露輪廓的量測 |
| `replays/` | 挑過的操作紀錄與說明（`replays/README.md`），可在遊戲的測試模式回放 |

### 2.1 `view`

- `me`：位置、生命、護甲板、裝甲、武器（每把的彈匣、備彈、射程、有效距離帶）、醫療包與各種道具數量、預備欄、技能狀態、壓制層數與釘住、失能、中毒、等待／瞄準／移動旗標、追擊與影步、手電筒、腳下亮暗、本層鑰匙卡、訊號斷層、下錨、迷彩。
- `enemies`：隊伍看得到的非平民敵人（`game.teamVisible`，和畫面一樣含友軍的視野），每個帶圖鑑數字（生命、裝甲、射程、傷害依樓層與難度換算、發數、連射、近戰、頭目、飛行、大型、快速、機械、自爆、狙擊）和目標卡顯示的狀態（蓄力、狙擊倒數、瞄準格、移動過、失能、菁英）。`civilians` 另列。
- `ghosts`：看過、現在看不到的敵人最後的位置（12 回合內；頭目一直記著）。
- `danger`：每個預告格（第 3.3 節）與它在幾個行動後結算。
- `known(x,y)`、`exit`（看過才有，含鎖住的理由）、看過的箱子、終端、油桶、地上物品、友軍。

### 2.2 意圖（intent）與執行

決策層只產生意圖：`{type, arg, target?, pre?, then?, plan?, why, score}`。

- `type`、`arg`：就是 `game.action(type,arg)` 的兩個參數（`move`、`fire`、`launch`、`grenade`、`skill`、`heal`、`reload`、`weapon`、`wait`、`openContainer`、`terminal`、`interact`、`deployUnit`……）；`perk` 另走 `game.choosePerk`。
- `target`：先設鎖定（玩家點敵人）。`pre`：先做的免費動作（換預備的投擲物、選撞擊武器）。`then`：前一個動作免費時接著做的動作（免費換槍後開火）。
- `plan`：選到這個意圖時同時立下的計畫（第 3.2 節）。
- 執行（`bot.act`）：被拒絕（回傳 `false`，遊戲設 `refusal`）時把這個意圖記進本回合的拒絕清單，重新決定，最多四次，之後等待一回合，不會無限重試。升級待選時先選升級。

### 2.3 每一步的順序（`bot.decide`）

1. 手電筒（免費）：有夜視（偵察兵、忍者、夜視鏡）就一直關著，黑暗是它的掩護；沒有夜視時腳下全黑就開，離開全黑兩個決定後關（槍口火光會把腳下照亮一回合，不加遲滯會每回合開關）。
2. 職業的免費動作（預警、訊號斷層、迷彩、起錨……）。
3. 有敵人或腳下有預告：戰鬥（第 3 節）。
4. 否則：職業的安靜時動作（造無人機、餵獸……）→ 治療、噴護甲板、裝填、換回主武器 → 接著走完進行中的接近計畫、守住撤退後的位置、等剛消失的敵人兩回合 → 開相鄰的箱子、用終端、撿或拆地上武器 → 目標（見下）。
5. 目標：40 步內的箱子、需要的物品、值得去的終端 → 去看剛消失的敵人 → 出口（本層探索完、或本層超過 260 回合、或「疲憊」）→ 最近的未探索格 → 頭目最後的位置 → 更遠的撿拾 → 穿過危險地形去探索 → 出口。
   - 「疲憊」：生命低於 45% 又沒有醫療包時，不再繞路撿東西，出口已知且開著就直接走。
   - 選了未探索格就一直走到那格被看見為止，不在兩個目標間來回。
6. 進度看門狗：新看到的格子、擊殺、經驗、廢料、醫療包、開過的箱子、造成的傷害都沒變時，每 20 個決定把看得到的敵人暫時不理 40 回合（被打到就取消），每 30 個放棄正在走去的探索格與遠處的撿拾，40 個之後「接近」改成不計代價的「強攻」（走到最近能開火的格子），90 個之後直接去出口。什麼都做不了時，先把不理的敵人找回來強攻，再穿過擋路的單位（走進敵人就是攻擊它）。

## 3. 戰術

### 3.1 評分（`combat.mjs`）

有敵人時列出這一回合所有可能的選項，全部用「生命點」打分，取最高：

- **吃到的傷害**（`damageCost`）：這格下一輪預期吃到的傷害 × 權重（生命越低越重），再加一個死亡項：這一輪（和三分之一權重的下一輪）運氣不好就死的機率 × 120。移動讓敵人 −22（笨重 −9）、等待傷害減半且 −15、掩體依角度 −35／−42 並減傷 45%、全都照規則的公式；被標定官標定時敵人 +15、+20%。
- **黑暗**：每一格的亮暗用遊戲自己的 `lightAt`（在唯讀副本上把自己的燈關掉，也就是畫面的明暗）。站在全黑的格子，沒有夜視、紅外線的非機械敵人看不到你（連貼身都看不到）；站在昏暗或全黑，沒有夜視的敵人開槍 −40。敵人的感官只看目標卡列出的特性（圖鑑的特性、已經現形的詞條，以及「蟲族在新照明下看得見黑暗」這條規則），沒現形的詞條不算。
- **每個敵人會打我多少**（`tactics.incoming`）：已蓄力的算下一輪（`now`），沒蓄力但有射線的算再下一輪（`soon`）；狙擊只打它瞄準的那格；近戰看距離與是否蓄力；自爆體貼身就是 30。蟲族頭目與除名狂戰士另算鉤舌（5 格內有射線）與衝鋒（同一列或行 2～8 格）。
- **攻擊**：目標卡的命中率（手上的槍直接用 `game.accuracy`，其他槍由它換算）、發數、每發傷害（彈種對裝甲的倍率、穿透、掩體減傷、能量打機械 ×1.2、標記 +10%），算出期望傷害與擊殺機率。得分＝擊殺機率 × 敵人價值（它接下來幾輪會打我多少）＋沒殺死時的部分價值＋**這一擊阻止的傷害**（在它出手前殺死一個已蓄力的普通速度敵人）−站著的代價−彈藥成本（精準步槍、電漿、霰彈槍較貴）−霰彈錐形裡的平民。
- **換槍**：用三輪來比：手上的槍連打三輪，還是換槍（這一輪不打）再打兩輪；只有明顯划算才換（再多 6 分的門檻），而且付費換槍後五回合內，除非手上的槍打不動，不再換回來。這讓它對裝甲 7 的敵人換步槍或電漿、貼身換霰彈槍，又不會每回合換來換去。
- **沒殺死的傷害**：也算進去（打掉的比例 × 敵人價值 × 0.8）：每一點傷害都縮短這場仗；只算殺死的話，機器人會對一隻打不死的巨蟲一直後退（「放風箏」到天荒地老）。
- **先打的人**：小隊長（讓整隊已就緒）× 1.6、督戰官（處決時全體齊射）× 1.3；在它出手前殺死的才算「阻止的傷害」（重裝兵很慢，普通速度的敵人都在它之前出手）。
- **撞擊**：相鄰的敵人可以用撞擊武器（或背包裡另一把近戰武器，免費選）打。
- **範圍**：破片手榴彈（半徑 2，不看護甲）、榴彈發射器、火焰噴射器的錐形；算進自己、友軍與平民的傷害，手榴彈留底（剩一顆更省）。
- **等待**：等待的防禦與下一發 +15（精準步槍解除瞄準懲罰）的擊殺機率增加；但只要打得到，已經在打我的敵人每多一輪就多打我一輪（「拖延」），而且連續等待還一直掉血時不再等待。
- **治療、裝填**、**移動**（每個相鄰格：那格的傷害、下一輪能不能從那裡開火、有沒有掩體、最近走過的格子扣分）。

### 3.2 有承諾的計畫（`stance.mjs`）

使用者的打法（主工作階段量了他的偵察兵／叛軍／困難的紀錄）：身上只要有一條沒掩護的射線就退到掩體或轉角，退兩三步後守住，從新位置開火。一步一步貪心評分會在兩個選擇間來回，所以改成計畫，照遊戲敵人的「命令」的做法（docs/ORDERS.md：做什麼、做多久、何時放棄）：

- `fallback`：身上有沒掩護的射線、或被三個以上看到時，找 10 步內最好的格子（`tileQuality`：沒掩護的射線 −14、有掩護的 −5、正好能打到一個 +6、預告格 −60、危險地形），比現在好到一個門檻才走。
- `retreat`：生命低於 35% 又被兩條以上射線看到時，找 18 步內完全不在任何射線裡的格子。
- `hold`：走到之後守著：能打就打，不能打就等待（防禦＋下一發穩定），最多四回合沒有敵人出現就放棄。
- `approach`：看得到敵人但打不到時，走到 14 步內能開火、而且站得住（終點的傷害也算）的格子；生命低於 40% 時不接近。
- **這場仗打不打得贏**（`fightOutlook`，使用者：很多局輸在一個逃不掉、該除掉的威脅因為幾發沒打中而沒有及時除掉）：每個正在打我的敵人每輪打我多少、我從這裡每輪能打它多少，照「每回合危險度 ÷ 擊殺時間」的順序一個一個殺，算出殺完之前我會吃多少；超過生命＋一半護甲板＋醫療包（最多三個 × 30）的四分之三，就算生命還高也當成「打不贏」，改成撤退（`retreat`）。打不動的威脅（我方的槍打不穿的裝甲、頭目）自然算成很長的仗。
- **用繩索脫身**：要撤退但走路出不去，或路上有兩條以上沒掩護的射線時，用逃命繩索（免費）或重部署鉤索（一回合）拉到 6 格內一個完全沒有射線的格子（規則自己的 `lineReason` 檢查能不能拉）。
- 計畫在沒有敵人的時候也會走完（敵人躲出視線不代表撤退結束），走到後守幾回合，再回去做本層的事。
- 路徑只選一次，之後照著走，下一格被佔或變成預告格才重找；計畫中的一步比同一回合的其他移動多 9 分（退守 +6、撤退 +20），所以只有明顯更好的事（很可能殺死一個馬上要開火的敵人、預告落在腳下）會打斷它。被釘住或下錨時不走計畫。
- 對峙（誰都打不到誰，連等三回合沒掉血）：有射擊位置就走過去，否則繼續本層的事。

### 3.3 預告與危險地形

`perception.mjs` 的 `dangerMap` 把畫面上畫得出來的預告都變成格子（只取看得到的格，和 `src/renderer-telegraphs.js` 一樣）：轟炸與飛行中的手榴彈（`g.marks`，依 `due` 算幾個行動後）、正在準備的手榴彈（落點半徑 1；震撼彈 3×3）、火焰兵的錐形、火線官的機槍扇形、縱火者的火牆與圍困、焚線官的火焰扇形、撲擊落點、毒囊落點、鉤舌整條線、衝鋒車道、卵囊、除名偵察兵的煙霧落點。危險地形（酸液、高熱、燃燒的地板、蒸氣、毒霧）只看探索過的格子。尋路與評分都會避開，沒有別的路才穿過。

### 3.4 其他

- 掩體與轉角：射線用遊戲自己的 `sight`／`shotClear`／`protectingCover`；估算敵人打某一格時把那格當成非單位，所以轉角的探身點算成暴露（偏保守）。
- 照明：見 2.3 與 3.1 的「黑暗」。
- 平民：不當目標，霰彈錐形與爆炸裡有平民會扣分（規則沒有懲罰，但使用者的試玩裡死了 13 個，機器人盡量不要）。例外是擋路（2026-10-04，使用者發現的卡關）：走向目標的路線把看得到的平民那格算成 `BOT_TUNING.civilianCost`（10）而不是牆，所以繞路超過 10 步才會選擇穿過；路線上第一個平民用手上的槍打掉（`clearWay`），打不到就走過去（撞上去就是近戰）。戰鬥中的走位仍然把平民當牆。在這之前，縮在一格寬通道裡（無處可逃）的研究員會把樓層剩下的部分封死：機器人不打平民，尋路又把看得到的單位當牆，走出視線後路線又通了，就在原地來回。
- 友軍：走向目標時，可以交換位置的友軍不加尋路成本（交換就是一步）；戰鬥中仍加 2，德魯伊的獵獸走路時也加 2（讓獵獸留在前面；全部改成 0 時德魯伊從 36/48 掉到 29/48）。換不了的（被壓制、哨戒機、一次性、失能、隔著隔板）一律加 50，第一步就是它時當成牆（規則會拒絕這一步；之前工程師被自己的無人機圍住，每個決定都重試同一步，叛軍、種子 108）。之前走路時每個友軍也加 2，死靈法師的亡靈跟在身後一直換位置，兩條差不多長的路每回合輪流變成最短，機器人就在原地來回（死靈法師、忠誠方、種子 5）。能不能換是從路線上「要換的那一格」判斷（`nav.mjs` 的 `swapFrom`）；規則的 `swapReason` 是從玩家現在站的格判斷，隔著隔板的亡靈從兩格外看起來換得過、走到旁邊才換不過，路線就每一步反轉（死靈法師、叛軍、種子 2 與 6）。
- 地上物品：撿不起來的（彈藥、投擲物、道具已滿，護甲板滿，裝備已穿；地圖上會變暗，`game.canTake`）不算目標。之前偵察兵會站上撿不起來的醫療包、從自己那格找不到目標就走開、再走回去，持續幾千回合。
- 最後的「硬闖過去」：出口還沒看到時也無視單位，走向未探索的格子（以前只有出口已知時才無視單位，所以守住通往未知出口的門口永遠推不過去）；第一步是可以交換的友軍也照走（以前第一步有友軍就不走）。
- 來回踱步（`bounce`）：走向目標的最近 8 步都在同樣三格以內來回、而且看門狗沒看到進展，這幾格在之後 30 回合裡走向目標的路線上加 25，逼它換一條路；戰鬥中的探身、退守不算。同一層第 3、6、9……次時放棄繞路的目標（終端、箱子、地上物品與武器、正要去的未探索格），直接找出口。遇到的情況：工程師的守衛無人機一直站在低隔板另一側正對面的格子（隔著隔板不能交換），每一步都選最近的翻越點，無人機就移到那裡，機器人又退回另一個（工程師、叛軍、種子 105；幾格外其實有沒有隔板的缺口）。這是遊戲的問題，3.222.3 已修（第 9 節第 3 項）；這個分支的遊戲是 3.209.0，所以機器人自己要能脫身。
- 門、隔板、翻越、鑰匙卡：尋路照規則的 `canRoute`；有本層鑰匙卡時上鎖的保險室門也算得過；走進門就開門。
- 箱子：每個看過的箱子都開（使用者每個都開），不看內容；叛軍設施的陷阱箱（點得到鎖定的那種）不開。
- 地上的武器：第二輪起照整包的覆蓋分數拿、換或拆（第 3.6 節）；第一輪是「沒有的槍種撿起來，其餘拆掉」。
- 終端：看種類（醫療、軍械、裝備）決定值不值得走過去；醫療：缺 40 以上就治療，醫療包少於 3 就買，護甲板差很多買噴劑；軍械：第二輪起改裝「每點廢料加最多分」的那一把，只替包裡重要的槍買彈（第一輪是固定的主武器）；裝備：破片少於 2 就買。
- 升級：職業各自的偏好表加一般的（生命在血少時、醫療補給在醫療包少時優先）。

### 3.6 武器組合（第二輪，2026-10-01）

使用者問：機器人會不會挑互補的武器（打裝甲的與打肉的、遠的與近的）？第一輪只有「戰鬥中換槍」做得好；撿槍只挑固定清單裡沒有的槍種放進空格，其餘一律拆掉，從不交換，也不看詞條與改裝；終端改裝固定改「主武器」。第二輪（`loadout.mjs`、`arsenal.mjs`）：

- **武器的用途**從武器卡（`Game.weaponAt`：傷害、發數、有效距離帶、穿透、彈種、詞條、已經買的改裝）算：對裝甲 0、1–2、3–5、6 以上各在 1、2、4、6 格一個行動的期望傷害（照規則公開的彈種對裝甲倍率、能量打機械 ×1.2、霰彈的彈丸數、爆炸不看裝甲、精準步槍約兩個行動一發），再乘上「能打多久」：彈匣＋備彈夠開幾次火（30 次算滿）、每次裝填花掉的回合，和這種彈藥好不好補（步槍彈、手槍彈最好補，霰彈、電池、榴彈依序變難，噴火器的燃料不能補）。
- **這一局要面對什麼**：部署時就知道設施的派系；敵人圖鑑有每張卡的生命與裝甲。從目前樓層到第 6 層，照派系的名單（早期／後期、忠誠方的小隊）加權，第 3、6 層的頭目各算好幾張（這是最需要對的武器的一仗）。
- **整包的分數**：每個威脅、每個距離，取包裡**最好的那一把**（乘能打多久），加權平均。取最大而不是加總，所以第二把槍只值「第一把做不到的部分」——這就是「互補」。
- **決定**：
  - 腳邊的槍：拿（有空格）、換掉包裡的某一把（被換的連同改裝留在地上，損失算在分數裡）、或拆成廢料，取分數最高的；要比現在高 6%（至少 1.5）才拿或換，避免換來換去。
  - 看得到但不在腳邊的槍，拿或換會加分就走過去。
  - 終端：改裝「每一點廢料加最多分」的那一把；只替「拿掉它包會少很多分」的槍買彈藥。廢料 100 以上時，任何有幫助的改裝都買，再買滿醫療包、治療小傷、補滿手榴彈；離開樓層前先去還沒用完的終端。
  - 平常手上拿的槍：單獨一把在接敵距離（2、4、6 格，以 4–6 格為主）對這一局一般敵人分數最高的。
- **戰鬥中**：換槍原本用「三輪」比；第二輪對血很多的目標（頭目）改用「這一仗會打幾輪」比（最多 8 輪），換槍只賠一輪，好槍每輪都賺；包裡彈匣空了但有備彈的槍也算（多花一回合裝填）。這讓打穿裝甲的槍真的拿出來打裝甲頭目。
- **打不動就走**：近處有一個包裡沒有任何一把打得動的敵人（每個行動打不到牠血量的十二分之一）時，當成要撤退；找不到撤退格、也沒有繩索時，至少往遠離牠的方向走。
- 另外兩個卡住的修正：出口被頭目鎖住又看過頭目時，去找頭目（不再在門邊來回）；在鎖住的出口旁邊不再走來走去。

## 4. 職業（`classes/*.mjs`）

鉤子：`perks`（升級偏好）、`prepare`（每回合先做的免費動作）、`combat`（加進戰鬥評分的選項）、`meleeBonus`（撞擊的額外價值）、`quiet`（沒有敵人時）、`beforeExit`（搭電梯前）、`stance`（計畫的設定）。

- **士兵**：預警（免費、冷卻 5）只要看得到或剛看過 8 格內的敵人就放：標記的敵人 +10 命中、+10% 傷害、黑暗中也鎖得到。升級：標定壓制、標定弱化、預警強化、沉著。
- **偵察兵**：被兩條以上沒掩護的射線看到、血少又被看到、或這場仗打不贏（`fightOutlook`）時放訊號斷層（免費，3 回合敵人看不到你）；手電筒永遠關著（夜視）；被多條射線看到時把煙霧彈丟在自己和射手之間（紅外線看得穿煙）。衝鋒槍的裝填免費，評分裡自動算成不花回合。
- **工程師**：一開始就部署生產線上的無人機；廢料夠就再造一台（或敵人藍圖、頭目藍圖）當備用；相鄰受傷的機體花 10 廢料修；地上的槍都拆成廢料（工程師 30）；搭電梯前等無人機靠過來（只有三步內的會跟著換層）。
- **德魯伊**：獵獸自己打；安靜時站在旁邊就餵：護甲板進護甲線、滿血時餵生命進活力線、獵獸重傷時餵醫療包；不餵砲塔線（一點燃料就會讓牠停在 3 格外射擊，不去咬）。
- **死靈法師**：召喚物自己起身、自己打；搭電梯前集結（免費）並等幾回合，讓它們進到三步內。
- **重裝兵**：守住的位置有目標、沒有兩條以上沒掩護的射線時下錨（攻擊加倍）；腳下有預告、被夾擊、戰鬥結束或血很少時起錨。撞擊用動力拳（免費換）。
- **狂戰士**：照使用者的打法：鉤鎖冷卻好就用，拉 2～5 格的敵人過來接斧頭（大型與頭目就衝過去），拉開會打斷它正在蓄力的攻擊；斧頭撞擊的嗜血回血算進撞擊的價值；只在血很少又被夾擊時退守。
- **忍者**：生命過半、而且迷彩開著（或冷卻好了）或站在暗處時進入「近戰模式」：走位時以相鄰目標的格子為好位置，用武士刀；6 格內有射手或 2 格內有敵人就開迷彩（免費，−30 被命中）；兩個以上可被震撼的敵人在 2 格內就把震撼彈丟在自己腳下（近距投擲不會震到自己）；近身時把煙霧彈丟在腳下（在煙裡武士刀一律伏擊 ×1.5）。

## 5. 給除名幹員用

幹員的回合可以用同一個決策層，差別在感知與執行兩端：

| 機器人 | 幹員要換成 |
| --- | --- |
| `buildView(game,memory)` 以玩家為中心 | 以幹員為中心的 `view`：`me` 換成幹員的卡片數字與狀態；`enemies` 換成它看得到的玩家與玩家的單位（`game.sight(e,target)`、`hiddenInDark`、`cloakedFrom`）；`danger` 換成**玩家這邊**畫面上的預告（玩家丟出的手榴彈、地雷、火、工程師的轟炸）；`known` 換成幹員自己探索過的格子（它需要自己的 `seen`，現在的敵人沒有） |
| `memory`（ghost） | 已經有：`e.lastKnown`、3.209.0 被攻擊時學到的來源格，可以直接當 ghost |
| 意圖 `move` | 敵人的一步（`e.x/e.y`，照 `nextStep` 的規則：門、翻越、危險地形） |
| `fire`／撞擊 | `attack(ctx)`（`src/enemy-behavior.js`），蓄力一回合的規則照舊 |
| `grenade`、`skill` | 幹員的招式登錄（`src/enemy-specials.js`：士兵的手榴彈與預警、偵察兵的煙霧、工程師的無人機、狂戰士的衝鋒與鉤鎖、忍者的迷彩），都要照 CHECKLIST 第 2 節預告一回合 |
| `heal`、`reload`、`terminal`、升級 | 敵人沒有；要不要給幹員醫療包是設計問題 |
| `stance`（退守、撤退、守住、接近） | 可以直接用；幹員的「掩護」照同一個 `protectingCover` |

缺的東西：幹員自己的探索地圖（`seen`）、它能看到的預告清單（`dangerMap` 的玩家版）、把意圖轉成敵人動作的執行層（而且要走 `enemy-specials` 的預告規則，不能在同一回合預告又出手），以及不讀玩家隱藏狀態的保證（例如玩家的訊號斷層、誘餌）。

### 5.1 將來：入侵者（使用者 2026-09-30 的初步規則）

使用者的最終目標：除名幹員有了自己的機器人之後，不只是樓層頭目，也能像黑暗靈魂的入侵靈體一樣**入侵一層**：每層用種子抽機率、佔該層敵人額度的一格；管制員的偵測警報宣告、出場照頭目演出；**只追玩家**，本層的敵人當它不存在（範圍傷害還是會打到它）；打倒給無盡模式的幹員屍體與點數；活著時電梯封住（暫定）。

這表示策略不能只會在頭目房裡打，要能在整層獵人。需要：

- **誠實的感知**：不看整張地圖、不讀玩家位置；只知道看到的、聽到的（遊戲目前沒有聽覺，使用者先不做）和被打到時學到的來源格。
- **自己的記憶**：玩家最後出現的位置與時間、走過的格子；玩家消失後去最後的位置找（機器人的 `investigate`），找不到就依探索過的地圖巡邏（反過來用 `exploreRoute`）。
- **追蹤與伏擊**：預測玩家往出口或往未探索區走；在轉角或門邊守著（機器人的 `hold`），而不是一直追進玩家的火力。
- **撤退與治療**：血少時離開視線（`retreat`）；有治療的話在視線外用。
- **職業技能與道具**：沿用各職業模組（煙霧、迷彩、鉤鎖、無人機……），但每一招都要走敵人招式的預告規則。
- **不被其他敵人當目標、也不當它們是隊友**：`enemies` 只放玩家與玩家的單位；範圍評分要把其他敵人算成「無關的人」（被波及不扣分也不加分）。
- **公平**：入侵者的預告要和頭目一樣清楚，玩家的訊號斷層、煙霧、誘餌要對它有效。
