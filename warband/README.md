# 戰幫・垂直切片

設計藍本的第一階段：證明「不微操的戰鬥也好玩」。網址：https://warband.darkbearlab.workers.dev

## 這個切片有什麼
- **大地圖是大陸沙盒**：60×48 六角格（種子「大陸-6」）。金冠王國在東南海岸立國，崩解後四百年間，人群一路往北、再越過中央山地往西開拓。墾民只在離自家市鎮三格內開墾、市鎮彼此至少隔四格，偶爾有人遠行五到九格另立新城，所以國土是一團一團的綠洲，中間隔著荒野，商路穿過荒野。一格約半天路（平地 12 小時，有路的地方再減半）。拖曳平移、雙指或滾輪縮放。
- **世界自己在動**：每 6 小時沙盒推進一個時段（一天 4 段、一季 7 天、一年 28 天）。列國打仗、盜匪聚散、商隊來往、價格每季重算；附近發生的事會以「聽說」傳進日誌。
- **跑商**：糧、木材、鐵、石材、鹽五種貨，每個市集的存量與價格都來自沙盒。按包買賣，買得越多越貴、賣得越多越便宜（同一季內累積，換季後由沙盒重算）；你賣進去的貨真的會進那座城的存貨。每人扛 1 包、騾子扛 8 包（騾子也要吃糧）。
- **興趣點**：荒野裡散著廢墟、山洞、廢棄的哨堡、沉船、隱士小屋、古神龕、古戰場；傳奇武器失落的地方會有「古林深處」「湖上的霧」。探索花半天，可能要先打一場（盜墓賊、野獸、逃兵、海盜），也可能撿到錢、特產、兵器、傳奇武器的線索，運氣好直接找到傳奇武器。探索過的六十天內沒東西可找。
- **地方特產**：毛皮（北地林區）、葡萄酒（溫暖的丘陵草原）、魚乾（海港）、寶石（山城）。只有產地買得到，離產地越遠賣得越貴；沙盒的商隊不跑這些，是玩家的生意。
- **行情**：只知道去過的市集的價格，和在酒館請一輪酒聽來的傳聞（越遠越舊）。
- **路上的危險**：盜匪多的格子容易遇伏，身上貨越值錢越容易被盯上；附近的山寨會派人追帶著貨的戰幫。付過路費時，貨比錢值錢他們就要一半的貨；撤退也會丟下一半的貨。
- **委託從沙盒長出來**：剿匪（真實的山寨）、護送商隊（帶著商隊更容易被盯上，付過路費或撤退就失敗）、收購（缺糧的城出高價收糧，不用接，送到就交貨）、傭兵（替交戰中的國家打前線，結果寫回那場戰爭）、狼害。懸賞回發佈的城或同國任一城領。
- **傳聞**：酒館裡可能聽到失落的傳奇武器在哪一帶；到那一帶每搜一天有機會找到。
- **戰爭迷霧與旅行**：只看得到走過、看過、聽說過的地方（市集可買附近的地圖）。一格大約一兩天的路，有商路的地方快；冬天路難走、北地吃得多；春汛時河邊難走。
- **危機看得見**：規劃路線時每一段依危險上色並列出摘要；交戰國之間的邊界是紅色戰線；饑荒的城標「饑荒」；追兵會標出來並連線到你；⚠ 按鈕開關危險圖層；「聽說」的事插在地圖上。
- **視野內的世界**：視野（虛線圈，看地形 1–3 格再加 1）內看得到沙盒裡真的在走的商隊與運貨車、交戰國在前線的大軍、各國的巡邏隊（會趕走盜匪）、山寨的嘍囉；視野外的看不到。城鎮套上國家的顏色，首都標 ★。
- **劫掠**：站在運貨車或商隊經過的格子上可以劫車（先跟護衛打一場），搶到的貨裝不下就丟在路邊，沙盒裡那批貨真的就沒了。被劫的國家會通緝你：通緝到一定程度，巡邏隊看到會追上來攔人（可以打、甩開或繳罰金）；再嚴重，他們城裡的告示板和酒館不跟你打交道。通緝會慢慢淡掉。
- **道路**：有商路的格子只花一半時間（之後改 AP 制就是省一半 AP）。
- **筆記**：右邊緣的「筆記」拉出來（或從右邊緣往左滑），可以打字，能插入目前日期與地點，跟著存檔。
- **花錢的地方**：鐵匠（兵器、護甲各三級，價格跟著鐵價走，要用掉城裡的鐵）、馬（全員有馬才走得快，也好甩掉追兵）、雇用有名者（沙盒裡真實存在的英雄，名聲夠才請得動；他戰死或離隊都會寫回沙盒，帶著的傳奇武器也跟著走）、把傳奇武器交給同伴佩帶。
- **名聲**：剿匪、從軍、護送、找到傳奇武器都會累積，影響請不請得動有名者。
- **山寨與傳奇武器**：告示板會懸賞附近沙盒裡真實存在的盜匪山寨。攻破山寨會讓那股盜匪從沙盒消失；如果寨裡藏著傳奇武器，就歸你，可以賣給城裡的權貴（武器的歷史會記下這一筆）。
- **生存壓力**：糧食吃光會掉血、掉忠誠；薪餉發不出來忠誠大掉；忠誠 ≤10 的人會不告而別。
- **戰鬥**：10×12 方格、回合制。你只操作主角；同伴依「命令」（跟著我／守住／進攻／集火／撤退）和個性行動。每回合開始時決定誰不聽令，所以畫面上的箭頭就是他們真正會做的事。
- **永久死亡**：同伴倒下就不會回來；主角倒下，旅程結束、存檔刪除。

## 檔案
- `public/js/data.js`：職業、武器（劍＞斧＞槍＞劍，弓只打 2 格）、地形、特性、命令、種子亂數
- `public/js/battle.js`：戰鬥規則，唯一入口 `act(st, action)`，回傳事件流；不碰畫面，之後可以直接搬到伺服器
- `public/js/world.js`：世界規則（戰幫這一層），唯一入口 `worldAct(w, action)`
- `public/js/cont.js`：大陸沙盒的接頭（載入、推進、存檔）；`public/js/sim/continent.js` 是 `continent` 分支 `continent/sim.js` 的複本，`codec.js` 負責把含 TypedArray 的狀態轉成 JSON
- `public/data/genesis.json`：創世檔，由 `node warband/tools/genesis.mjs [種子]` 產生（推演 400 年，約 5 秒）
- `public/js/app.js`：畫面
- `public/art/`：由 `tools/slice.py` 從 gpt-image 的 sprite sheet 切出來
- `test/battle-sim.mjs`：決定性檢查與 1,800 場戰鬥平衡模擬；`test/world-sim.mjs`：跑商機器人（作弊看得到 8 格內行情）跑 N 局 × N 天

## 共享世界（多人）
- `server/worker.js`：Cloudflare Worker ＋ Durable Object `Realm`。整片大陸只有一份，存在 DO 的 SQLite（gzip 後切 500 KB 一塊）。
- 世界時鐘：鬧鐘每 `TICK_SECONDS`（預設 120 秒）推進一個時段（6 小時），所以現實 8 分鐘＝遊戲 1 天。
- 行動點：1 AP＝1 小時，回復速度和世界時鐘一樣，上限 `AP_MAX` 120；離線時戰幫原地不動、不吃糧不發餉。
- 伺服器說了算：玩家每個行動送 `/api/act`，伺服器跑 `worldAct`。戰鬥在瀏覽器打，打完把操作紀錄送 `/api/battle`，伺服器用同一顆種子重播，結果以伺服器為準。
- 瀏覽器從 `/api/snapshot` 拿唯讀鏡像來畫地圖、查行情；`/api/world` 有世界時間與其他玩家位置（地圖上會畫出來）。
- 身分：用 Google 帳號登入（`server/auth.js` 驗 Google 的 ID token，不需要密鑰；用戶端 ID 在 `wrangler.toml` 的 `GOOGLE_CLIENT_ID`），伺服器發一個工作階段代碼，一個 Google 帳號一個角色、跨裝置。第一次登入會把這個瀏覽器原本的訪客角色搬過去。`ALLOW_GUEST = "0"` 可以關掉訪客（訪客＝瀏覽器 localStorage 裡的隨機代碼）。名字不能重複。隱私權政策在 `public/privacy.html`。
- 管理：`ADMIN_EMAILS` 裡的 Google 帳號登入後，標題畫面有「管理」：看所有戰幫、刪某支戰幫、暫停／繼續世界、重開世界（清空世界、角色、帳號與登入，要輸入「重開」）。玩家自己可以在隊伍詳情「解散戰幫」（刪角色重建），或在標題畫面「刪除帳號」。
- 開關：`wrangler.toml` 的 `WORLD_VERSION` 改值＝換一個全新的世界（舊的資料留著但不再用）；`PAUSED = "1"` 暫停時鐘；`TICK_SECONDS` 調速度。
- 本機：`npx wrangler dev --config warband/wrangler.toml --local --var DEV:1 --port 8790`（`DEV` 開啟 `/api/dev/fight` 測試用）。

## 急行軍、載重、地上的貨、採集、送信、打零工
- 載重：貨裝到七成五以上每格變慢，滿載多花四成時間（`loadMul`）。
- 急行軍（路線資訊的開關）：每格少三成時間；每小時全隊 −0.6% 生命、傭兵忠誠 −0.1、騾子 0.3% 倒下、馬 0.15% 跛腳；疲憊值（急行軍 +1/小時，休息 −2/小時；共享世界等行動點也算休息）大於 0 時打仗防禦 −1、命中 −10，離線夜襲也吃這個。共享世界裡就是「用更少的行動點走同一段路」，不能欠行動點。
- 地上的貨：行囊裡可以丟下任何貨；扛不動丟下的、撤退時丟下的、沙盒劫案散落的、被盜匪盯上的商隊丟下的，都變成那格的貨堆。視野內看得到、走到就能撿（2 小時）。會爛（糧最快），離村子城鎮近的會被撿走並算進最近市集的存貨。共享世界的貨堆在伺服器上共用。
- 採集（野外格子資訊的「採集…」）：打獵（口糧、毛皮，扣沙盒獵物量）、伐木（扣林木量）、採石（丘陵山地）、挖礦（礦脈，要紮營工具，扣礦脈）、曬鹽（海岸鹽地，一天）。在有主的土地上算盜採，被巡守撞見記通緝、沒收一半。沙盒的 `peek()` 為此多開放了 `timber`、`timberK`、`vein`、`known`。
- 送信（告示板）：捎信到 3–10 格外的城，錢少；四分之一是密信，酬勞三倍，但會有「截信的人」追來，付錢或撤退就失敗。
- 打零工（旅店分頁）：全隊一天賺幾塊錢，城越大越多。

## 此地：同一格的對話與留言
- 右欄「此地」：這一格的人（在不在線上）、即時對話、留言。
- 對話走 WebSocket（`/api/ws`，Durable Object 的休眠 API，沒人講話時不計時間）；伺服器只轉給此刻在同一格（看 roster 的位置）、連著線的人，不存紀錄。講一句花 0.25 行動點、最快 1.5 秒一句、140 字。說話的人頭上冒 8 秒的泡泡。
- 留言（`/api/tilenote`）：1 行動點，留在那一格三天，每格最多 12 則；地圖上有 📜 標記。
- 訪客只能聽、看（`ALLOW_GUEST_CHAT = "1"` 可開放）。管理頁可以禁言。
- 單人模式先藏起來（標題畫面不顯示），以線上為主。標題畫面「更新紀錄」讀 `public/changelog.json`，每天第一次進來自動跳出。

## 建立角色與頭像
- 單人「踏上旅程」或共享世界第一次進入（帳號還沒有角色、或上一支戰幫散了）時，進「建立角色」：名字（共享世界會抽一個沒人用過的、打字時即時檢查）、性別、出身、頭像。
- 出身（`ORIGINS`，world.js）：落魄騎士、老兵、商家子弟、獵戶、修道院出身、亡命之徒。只影響開局（職業、錢、同伴、騾馬、名聲、行情、通緝）和角色身上的標籤。主角比同職業傭兵多 3 血、力量與防禦各 +1。
- 頭像庫：`public/art/faces.webp`（128px 一格、12 欄）＋`faces.json`（每張的性別、年紀、描述）。由本機 Claude Code 用 gpt-image-2 產的 122 張（暫用）。主角存 `face`；傭兵存性別 `g` 與種子 `fs`，畫面依性別挑一張。地圖上的戰幫（自己與其他玩家）都畫成圓形頭像，外圈是旗子的國色。

## 畫面（2026-10 改版）
- 左欄：主角卡（血、等級、錢、聲望、糧、載重、騾馬、行動點、旗子）＋同伴列表；點了開詳細卡片。手機上收成左上角的小卡。
- 右欄：日誌、聽說、行情、委託、筆記五個分頁；每一條旁邊的「＋筆記」會帶著時間地點抄進筆記，筆記裡的地名點了跳到地圖。手機上收成右邊一排直的分頁。
- 中間：紅色的「此地」鈕（`renderHub`）。按下去往上疊開：這格上的人（盜匪、商隊、運貨車、巡邏隊、別的戰幫，點了開各自的行動卡）和這格能做的事（進城／進村、探索、撿貨、採集、搜尋、紮營…）。點自己所在的格子，小卡只剩資訊。
- 路上的人（`caravanDeal`、`cartDeal`、`patrolHire`；動作 `trade`、`ask`、`hirePatrol`、`attackPatrol`，各一小時）：商隊只賣車上那種貨，價格在出發地與目的地行情之間依進度內插，剛出發貨多會打折、收貨價一定低於賣價且越接近目的地越低，受商隊載量（初始量 ×1.3）限制；買賣直接增減沙盒商隊的貨，共享世界畫面用 `mirrorTrade` 在鏡像上照做。運貨車照目的地價九五折賣收成與口糧。被通緝、掛交戰國旗會被拒；人比護衛多會加價，多太多直接拒絕；名聲打折。巡邏隊同行 `w.guard`：一兵一天 6 金幣＋5，12／24／48 小時，戰幫時間或世界時間先到就走，出國境或被通緝也走；期間埋伏機率 ×0.25、狼 ×0.5、山寨派人 ×0.3，戰鬥時以友軍上場（`battleParty` 帶上，不吃糧、陣亡不算同伴）。
- 單挑（`duel`）：盜匪隊伍或山寨頭目，只有主角上場（`battleParty(w, setup)` 看 `setup.duel`）。接受機率 `duelOdds`（聲望、戰力比）；被拒的盜匪直接圍上來。主角倒下＝認輸（hp 1），照 `tollOf` 交過路費。打倒的頭目綁成 `w.bound`，`handOver` 在城裡換賞金（剿匪委託已完成就加五成），每天 4% 逃掉。
- 人情（`w.favor`，以市集格為一區 `regionOf`）：`addFavor`／`spendFavor`／`favorAt`（每天 ×0.97）。用途 `FAVOR`：`lodge` 借宿（`w.lodged`，離線時 `idle` 視同住店、不吃糧、不被夜襲）、`askLocal` 打聽山寨、`hide` 躲巡邏隊、`favorRansom` 贖人。村子請託 `villagePleas`（每村一週一批：狼害、惡霸 `thugs`、尋人 `missing`），回村 `thankPlea`。
- 主角被打倒（`heroDowned`）：官兵一定抓；盜匪看 `worthOf` 留活口，否則死；野獸看同伴忠誠拖回來，否則死；單挑認輸不死。被抓成 `w.captive`，拿走八成的錢、所有貨、一件裝備；被抓時只能 `payRansom`、`favorRansom`、`escape`（12 小時）、`waitCaptive`（24 小時），期滿自動放人（`CAPTIVE_DAYS`）。野獸、玩家對戰只丟貨。
- 羅賓漢：`give` 接濟村子換人情（`giftFavor`、`foodNeed`），貨真的進市集；借宿＝藏身（`hidden`、`hideCharge` 照世界時間付遞增的人情），名單 `hidden` 的人不出現在 `/api/world`，也不能被襲擊。
- 躲藏（`concealment`：village／den／forest／deep）：`hidden` 給名單、巡邏隊、盜匪用；`expose` 打劫單挑後半天藏不住；`hideIn` 躲進 `HIDE_POI`，`denRisk` 每六小時可能出事；伺服器 `seek` 在 `searchTile`／`explore` 時依 `findOdds` 找出同格躲著的戰幫，設 `exposedH`。
- 裝備（data.js `ITEMS`、`weaponOf`、`gearAdd`、`armorSprite`；world.js `kitOf`、`fixGear`、`smithStock`、`itemPrice`、`battleLoot`）：`toUnit` 把裝備加成算進數值並記在 `u.gearAdd`，`applyBattle` 扣回。動作 `equip`、`unequip`、`dropItem`、`buyItem`、`sellItem`、`upgradeItem`。貨堆可以有 `items`。
- 戰場（battle.js）：`st.W`、`st.H` 隨戰況決定（`sizeFor`、`LAYOUTS`、`spawns`、`genMap(seed, biome, W, H, layout)`），最短路用桶子佇列。騎馬 `mounted`（`moveCost`）。撤離看 `exitAt`。共享世界的戰鬥狀態在伺服器 `p.battle.st`，每步走 `/api/battle/act`；`test/layout-sim.mjs` 跑各種戰場的勝率與耗時。
- 頭像（art/faces.webp＋faces.json）：48×48 像素版，由原本 128px 的頭像表逐格跑 asset_generator 的 sprite_quantize（`--target-long-edge 48 --colors 16 --bg none`，保留底色）後重新拼成；畫面一律不平滑放大（`image-rendering: pixelated`、`imageSmoothingEnabled = false`），圖片網址帶 `?v=尺寸` 避免舊快取對不上。
- 通緝要有人報信：劫車隊或打巡邏兵，打贏但有敵人逃走、或自己撤退，才記通緝；全殲沒人知道。

## 紮營與防守
- 紮營（免費）、設哨（多吃 1/4 糧，敵人只能從遠處來）、木柵（2 包木材或在林地砍樹，戰場上圍一圈只留缺口）、營火（回血快、冷天必備，但盜匪更容易找上門）。紮滿 12 小時（有紮營工具 6 小時）才算紮穩，防禦 +1。移動就拔營。
- 防守戰打輸照順序掉：一半的貨 → 四成的錢（60 以上才拿）→ 木柵／哨 → 一個同伴（一半逃散、一半被抓走，可到酒館贖回）→ 只剩主角。主角不會在防守戰裡死。
- 共享世界的離線：行動點滿了以後的時間算離線，糧吃 1/3、餉發一半；在城裡改付旅店錢、不吃糧、也不會被攻擊；在野外可能被夜襲（直接用數字算，營地越好越守得住）。
- 旗子：在城裡的旅店掛上那國的旗（招人八折、替它打仗的賞金多 25%）；在跟它交戰的國家境內，巡邏隊會追著打，別的戰幫打你也不算犯法。
- 襲擊其他玩家：同一格、不在城裡、對方不在保護時間（被洗劫後 24 個時段）內。打一場由 AI 防守的戰鬥（營地地形＋防禦補償）；贏了照上面的順序搶。在有主的土地上打沒掛敵旗、沒被通緝的人，會被那國通緝。
